# GOAL (Generative Offline Assisted Labeler)

A data labeling tool for on-device data labeling tasks.

- 100% offline
- macOS desktop app for
- CSV data labeling
- powered by **Gemma 2 2B**
- powered by Apple Silicon Metal acceleration

## Development Setup

1. **Clone repository:**
   ```bash
   git clone [https://github.com/matheuswisniewski/goal.git](https://github.com/matheuswisniewski/goal.git)
   cd YOUR_REPO_NAME
   ```
