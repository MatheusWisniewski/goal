# GOAL (Generative Offline Assisted Labeler)

[![Version](https://img.shields.io/badge/dynamic/json?url=https%3A%2F%2Fraw.githubusercontent.com%2Fmatheuswisniewski%2Fgoal%2Fmain%2Fversion.json&query=%24.version&label=Version&color=007AFF&style=for-the-badge&logo=apple)](https://github.com/matheuswisniewski/goal/releases/latest)

A data labeling tool for on-device data labeling tasks.

- 100% offline
- macOS desktop app for
- CSV data labeling
- powered by **Gemma 2 2B**
- powered by Apple Silicon Metal acceleration

## 📥 Download

Click the **Version badge** above or go to the [Latest Release Page](https://github.com/matheuswisniewski/goal/releases/latest) to download the installer (`DataLabeler.dmg`).

### Quick Installation Guide

1. Go to the [Latest Release Page](https://github.com/matheuswisniewski/goal/releases/latest) and download the `.dmg` file under **Assets**.
2. Double-click the downloaded installer.
3. Drag **DataLabeler.app** into your **Applications** folder.
4. **Right-Click (or Control-Click)** `DataLabeler` in Applications and select **Open** _(first time launch only)_.
